Music

World explorer and Midnight modem are original instrumental themes written for this atlas. The sound engine generates two-operator FM-style voices at 22,050 Hz, quantized to signed 16-bit PCM, with an optional PC-speaker-style square voice. The speaker voice uses the integer frequency table and timer-divider calculation measured by static analysis of PC Globe 5.04; it synthesizes the independently licensed scores listed below. Sound Blaster is a historical reference to the timbre, not a claim of hardware emulation.

43 country entries, 36 melodies: opening excerpts from anthem-scores 0.1.1 by Marian Becher. Note data is redistributed unchanged with its original per-file source license (public domain / CC BY-SA). These licenses apply to the score data; the web player is a separate implementation. Upstream credits · Upstream code license · CC BY-SA 4.0 · CC BY-SA 3.0. Synth timbres are newly generated; no original PC Globe audio is bundled.
