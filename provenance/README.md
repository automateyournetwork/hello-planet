The retro feature was incorporated from the exact source used for the November 24, 2026 production release at 17:56:18 UTC. Home configuration and sample-history labels were then adapted for this standalone project.

No private hosting data, original DOS software, or production visitor store is included. Public asset origin/license details remain in public/pc-globe/manifest.json and ATTRIBUTION.md.
